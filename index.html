04 — Featured Projects

Identity & Authorization Gateway for AI Agents In progress

A personal build of “OAuth, but for agents”: a service that lets AI agents act on behalf of users with scoped, short-lived, revocable delegated authority. A user grants an agent a scope; the gateway issues a short-lived token, and any delegation to a sub-agent can only narrow that scope, never widen it. A policy engine decides whether a sensitive action is allowed, denied, or paused for human approval (deny-by-default on timeout), and every action lands in a tamper-evident, hash-chained audit log. Revoking a grant propagates in seconds, killing every downstream delegated token with it.

Python / FastAPI · JWT / OAuth 2.0 token exchange · Docker

Recipe-Costing — Invoice Document Intelligence
